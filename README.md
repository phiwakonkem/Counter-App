# Counter App

A simple tally counter with Increase, Decrease, and Reset buttons — handy for counting during events like stone skipping (counting how many times a thrown stone skips on water).

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black)

## Features

- Increase / Decrease / Reset the counter
- Simple, distraction-free single-screen UI

## Tech Stack

HTML5 · CSS3 · Vanilla JavaScript

## Getting Started

```bash
git clone https://github.com/phiwakonkem/Counter-App.git
cd Counter-App
```

Open `index.html` directly in your browser.
